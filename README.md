# RAT HOME — Крыски дома 🐭🏡

Уютная интерактивная 3D-игра про декоративных крысок в просторной клетке для Android.
Создана на **TypeScript + Three.js (WebGL2) + React + Tailwind CSS + Capacitor** с полностью автоматической облачной сборкой `.apk` через **GitHub Actions**.

На стене игровой комнаты бережно размещена памятная деревянная табличка **«Посвящается : Тимме, Жоржу, Васе, Элвину»** (на неё можно нажать в 3D или открыть кнопкой ♥ в верхнем меню).

---

## Что есть в игре
- **Реалистично-иллюстративная 3D-графика** с мягким домашним освещением, иерархическим скелетом крысок, процедурными текстурами шерсти (гладкая и волнистая рекс), ушками стандарт/дамбо, подвижными усиками и 9-сегментным гибким хвостиком.
- **20 готовых окрасов** (включая фирменную белую с серой полоской по спине в двух вариантах — с серой «шапочкой» и с белой головой) + свободный конструктор базового цвета и рисунка.
- **Живой ИИ (Utility AI)** с циклами активности и отдыха: прогулки, обнюхивание, стойка на задних лапках, умывание мордочки и шубки, поедание лакомств из лапок, питьё из поилки, перенос салфеток в гнездо, лазание на 2-й этаж, туннели, сон в гамаке и домике, социальный груминг и весёлая возня.
- **Общение и трюки:** угощения, поглаживания с вибрацией и поскрипыванием зубками, подзыв по имени, игра с пёрышком, обучение 5 трюкам («Поворот», «Лапка», «Стойка», «Через кольцо», «Принеси шарик»).
- **4 режима камеры:** общий обзор, уровень крыски, слежение и чистый **фоторежим** с альбомом и экспортом снимков на Android.
- **Магазин и 3D-обустройство клетки:** 9 разделов (корма, домики, гамаки, туннели, игрушки, уход, клетки/манеж, 4 темы комнаты и расширение до 2-го этажа).
- **Гибкие настройки жизненного цикла:** отдельные переключатели для разведения (выкл. по умолчанию), старения, естественной смерти (с выбором продолжительности жизни) и комфортного режима.
- **Автосохранение** прогресса и фотоальбома в `IndexedDB` / `localStorage`.

## Как собрать и скачать `RAT HOME.apk` на телефон через GitHub (без Android Studio на ПК)

### Шаг 1. Загрузите проект на GitHub
1. Создайте новый репозиторий на [github.com](https://github.com/new) (например, `rat-home`).
2. Откройте терминал в папке проекта и выполните:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: RAT HOME 3D game"
   git branch -M main
   git remote add origin https://github.com/<ВАШ_ЛОГИН>/rat-home.git
   git push -u origin main
   ```

### Шаг 2. Дождитесь автоматической сборки APK
1. Откройте ваш репозиторий на GitHub и перейдите во вкладку **Actions**.
2. Сразу после отправки кода в ветку `main` автоматически запустится рабочий процесс **«Build RAT HOME Android APK»** (его также можно запустить вручную кнопкой **Run workflow**).
3. Подождите 3–5 минут, пока напротив сборки появится зелёная галочка ✅.

### Шаг 3. Скачайте и установите `.apk` на Android
1. Нажмите на завершённый запуск **Build RAT HOME Android APK**.
2. Прокрутите вниз до раздела **Artifacts** и нажмите **RAT-HOME-APK**, чтобы скачать архив.
3. Распакуйте архив и перенесите файл **`RAT HOME.apk`** на телефон (или скачайте архив сразу со смартфона).
4. Откройте `RAT HOME.apk` на телефоне и разрешите установку из неизвестных источников, если Android попросит подтверждение.

> **Опционально — подписанный Release APK:** если вы хотите подписывать релизную сборку собственным ключом, добавьте в *Settings → Secrets and variables → Actions* четыре секрета: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`. После этого GitHub Actions дополнительно соберёт `RAT HOME-release.apk`.
