# 🐀 Крыски дома

Уютная 3D-игра для Android про декоративных крыс: заведи крысок, настрой их внешность и характер, обустрой двухэтажную клетку, корми с руки, гладь, играй с пёрышком, учи трюкам и фотографируй.

*Посвящается Тимме, Жоржу, Васе и Элвину* 💕

**Технологии:** TypeScript · Three.js (WebGL2) · React · Tailwind CSS · Vite · Capacitor 6.
Вся графика (модели крыс, шерсть, клетка, предметы, комната) и весь звук создаются кодом — внешних моделей и аудиофайлов нет.

## 📲 Как получить APK на телефон (без настройки ПК)

### 1. Загрузите проект на GitHub
1. Зарегистрируйтесь или войдите на [github.com](https://github.com).
2. Нажмите **«+» → New repository**, задайте имя (например, `krysky-doma`) и нажмите **Create repository**.
3. На странице нового репозитория нажмите **«uploading an existing file»**.
4. Распакуйте архив с проектом на компьютере и перетащите **содержимое** папки `krysky-doma` (файлы `package.json`, `src`, `.github` и т. д.) в окно браузера.
   > ⚠️ Папка `.github` скрытая. Если браузер её не загрузил, создайте файл вручную: **Add file → Create new file**, имя `.github/workflows/build-apk.yml`, и вставьте содержимое из архива.
5. Нажмите **Commit changes** (ветка — `main`).

### 2. Запустите сборку
Сборка запускается **автоматически** после каждого изменения в ветке `main`.
Запустить вручную: вкладка **Actions** → слева **«Сборка APK»** → **Run workflow** → **Run workflow**.

Сборка длится около 5–10 минут. Зелёная галочка ✅ — всё готово.

### 3. Скачайте APK
1. Откройте вкладку **Actions** и нажмите на последнюю успешную сборку.
2. Внизу, в разделе **Artifacts**, скачайте `KryskiDoma-debug-apk-…` (это zip-архив).
3. Распакуйте его — внутри файл `KryskiDoma-v1.0.N-debug.apk`.

### 4. Установите на Android
1. Перешлите APK на телефон (Telegram «Избранное», Google Диск, USB-кабель…).
2. Откройте файл на телефоне. Если появится предупреждение — разрешите **«Установка из неизвестных источников»** для приложения, через которое открываете файл.
3. Нажмите **Установить** — и знакомьтесь с крысками! 🐀

> Debug-версия полностью рабочая. При обновлении достаточно поставить новый APK поверх старого — прогресс сохранится.

## 🔐 (Необязательно) Подписанная release-версия

Если в репозитории заданы секреты, сборка дополнительно создаёт подписанный `release` APK.

1. Создайте ключ (один раз, на любом компьютере с Java):
   ```bash
   keytool -genkey -v -keystore release.keystore -alias krysky -keyalg RSA -keysize 2048 -validity 10000
   base64 -w 0 release.keystore > keystore.txt
   ```
2. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**:
   | Имя | Значение |
   |---|---|
   | `ANDROID_KEYSTORE_BASE64` | содержимое `keystore.txt` |
   | `ANDROID_KEYSTORE_PASSWORD` | пароль хранилища |
   | `ANDROID_KEY_ALIAS` | `krysky` |
   | `ANDROID_KEY_PASSWORD` | пароль ключа |

Храните `release.keystore` в надёжном месте и **не загружайте его в репозиторий**.

## 🎮 Что есть в игре

- **Кат-сцена** при первом запуске (с кнопкой «Пропустить») и табличка-посвящение на стене комнаты.
- **Выбор питомца:** центр пристройства, заводчик или зоомагазин; 3D-превью крыски.
- **Конструктор внешности:** 20 готовых окрасов (№1 — в двух вариантах: с белой головой и с серой «шапочкой»), отдельно цвет и рисунок, глаза (с учётом сочетаемости), ушки стандарт/дамбо, шерсть гладкая/рекс, пол, имя, характер.
- **3D-крыса:** гибкий позвоночник, мех (процедурные текстуры + shell-слои + мягкий rim-свет), живые глаза с бликом, подвижные усы, лапки с пальчиками, хвост из 10 сегментов с пружинной инерцией.
- **Поведение (Utility AI):** еда лапками из миски, питьё из поилки, умывание, вычёсывание, стойка, сон в домике/гамаке/на подстилке, перенос салфеток в гнездо, лазание по прутьям, лесенкам и пандусу на 2 этаж, туннели, колесо, мячик, фуражилка, взаимный груминг и игровая возня. Циклы активности и отдыха.
- **Взаимодействие:** лакомство с руки, поглаживание пальцем (с вибрацией), «позвать по имени», игра с пёрышком/мячиком, дрессировка 5 трюков, фото.
- **Карточка питомца:** возраст, пол, окрас, характер, шкалы (сытость, здоровье, комфорт, доверие), любимые игрушки, трюки, родословная.
- **Магазин:** корма, домики, гамаки, туннели, игрушки, уход, клетки и манеж, темы комнаты, второй этаж. Режим обустройства со слотами.
- **Задания и достижения**, монетки за заботу.
- **Настройки:** разведение (по умолчанию выключено), старение, естественная смерть, комфортный режим, длительность жизни (1 час … как в жизни), звук, вибрация, качество графики.
- **Фоторежим** без интерфейса и **фотоальбом** с экспортом на устройство.
- **Автосохранение** (localStorage + IndexedDB) и мягкий расчёт времени, пока игра была закрыта.

**Управление камерой:** 1 палец — вращение, 2 пальца — приближение. Режимы: «Обзор», «Низко» (уровень питомца), «Следить», «Фото».

## 🛠️ Локальная разработка (по желанию)

```bash
npm install
npm run dev         # игра в браузере: http://localhost:5173
npm run typecheck   # проверка типов
npm run build       # сборка в dist/
```

Сборка APK локально (нужны Android Studio / Android SDK и Java 17):
```bash
npm run build
npx cap add android        # один раз
npx cap sync android
npm run android:prepare    # ориентация, иконки, полноэкранный режим
cd android && ./gradlew assembleDebug
```

## 📁 Структура

```
src/
  engine/   движок: рендер, камера, комната, процедурные текстуры, реквизит
  rats/     3D-модель крысы, шерсть, окрасы
  ai/       поведение (Utility AI), анимации поз, навигация, мир клетки
  cage/     раскладка клетки и слоты, 3D-предметы
  store/    состояние игры, данные (окрасы, предметы, задания), сохранения
  ui/       интерфейс (React + Tailwind)
  audio/    синтезированный звук (Web Audio API)
  platform/ вибрация, сохранение и «Поделиться» (Capacitor)
scripts/    подготовка Android-проекта
resources/  иконки приложения
.github/workflows/build-apk.yml   автосборка APK
```
