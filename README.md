# RAT HOME — Крыски дома (Godot 4.3 + Blender 5.2) 🐭🏡

Уютная 3D-игра про декоративных крысок на **Godot 4.3** (`GL Compatibility` для плавной работы на Android), развивающая наработку `krysky_doma_wip` с **новыми скульптурными 3D-моделями крыс из Blender 5.2**, **новой логикой Utility AI** и полным мобильным интерфейсом на русском языке.

На задней стенке клетки в тёплой дубовой рамке размещена памятная табличка **«Посвящается : Тимме, Жоржу, Васе, Элвину»** (на неё можно нажать в 3D или открыть кнопкой ♥ в верхнем меню).

---

## Что нового и доработанного
- **Новые 3D-модели крыс из Blender 5.2** (`assets/models/*.obj` + новый `scripts/rat_model.gd`):
  - Цельный скульптурный корпус (`rat_torso.obj`) и анатомичная голова (`rat_head.obj`) с мягкой шеей и суженной мордочкой (вместо разрозненных сфер).
  - Скульптурные вогнутые ушки (`rat_ear_standard.obj` и `rat_ear_dumbo.obj`), бёдра, передние лапки и кисти с пальчиками (`rat_front_paw.obj`, `rat_hind_paw.obj`).
  - Процедурный шейдер шерсти (`shaders/fur.gdshader`) для всех 20+ окрасов и типа шерсти «Рекс» + мягкая внешняя shell-оболочка, 12 живых усиков и инерционный 14-сегментный хвост.
- **Новая логика ИИ (`scripts/rat.gd`):**
  - Utility-AI с естественными циклами активности и отдыха (крыски чередуют исследование, лакомства, уход за собой, игры, социальный груминг/возню и уютный сон в гамаке со свешенным хвостиком или в домике).
  - Плавная инерция поворотов, перенос салфеток в гнездо, бег через туннели и по колесу, подъём по пандусам на 2-й и 3-й этажи.
  - Тёплые взаимодействия: прямое поглаживание пальцем по крыске с поскрипыванием зубками и вибрацией, угощение, подзыв по имени, игра «охота за пальцем» и дрессировка 7 трюков с 3D-реквизитом.
- **Полный интерфейс (`scripts/ui/hud.gd`):**
  - Вступительная кат-сцена с кнопкой «Пропустить», выбором происхождения и конструктором первой крыски (по умолчанию — белая с серой полоской по спине).
  - Карточка питомца, магазин (9 разделов + Центр знакомства), уход и мягкая уборка, задания/достижения, чистый фоторежим и фотоальбом.
  - 4 независимых переключателя жизненного цикла (*Разведение* выкл. по умолчанию, *Старение*, *Естественная смерть* с выбором продолжительности жизни `1 час / 3 часа / 2 дня / 1 неделя / 1 месяц / 3 месяца`, *Комфортный режим*).

## Автоматическая сборка `RAT HOME.apk` в GitHub Actions
1. После отправки кода в ветку `main` автоматически запускается workflow **«Build RAT HOME Android APK (Godot 4.3)»** (`.github/workflows/build-apk.yml`).
2. Во вкладке **Actions** откройте завершённый запуск и скачайте артефакт **`RAT-HOME-APK`**.
3. Распакуйте архив и установите **`RAT HOME.apk`** на Android-смартфон.
